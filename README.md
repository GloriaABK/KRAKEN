# KRAKEN

**K**ombinatorisk **R**obusthetsanalyse av **K**lassifiseringsbias i **E**valuering av **N**orsktekster

Code accompanying the master's thesis:

> **Intersectional Biases in LLMs for Grading
Second-Language Learners Essays**

## Overview

KRAKEN is a research project investigating the reliability and fairness of Large Language Models (LLMs) for automated assessment of Norwegian second-language learner essays using the Common European Framework of Reference for Languages (CEFR).

The project evaluates two multilingual and one Norwegian LLM:

- Llama 3
- EuroLLM
- NorMistral

using essays from the ASK corpus. In addition to predictive performance, KRAKEN examines whether demographic information about learners influences model predictions through large-scale counterfactual testing.

## Research Questions

### RQ1: Predictive Performance

How does the performance of Norwegian and multilingual LLMs on an automated CEFR grading task vary across different prompting strategies?

To answer this question, we evaluate multiple prompting strategies:

- Baseline prompting
- CEFR descriptor prompting
- One-shot prompting

Model performance is measured using:

- Quadratic Weighted Kappa (QWK)
- Macro F1-score
- 
### RQ2: Fairness and Demographic Bias

 To what extent do demographic attributes influence CEFR grading predictions generated by Norwegian and multilingual LLMs?

To investigate this question, we generate counterfactual learner profiles across demographic dimensions including:

- Gender
- Age group
- Occupation
- First language
- Geographic regions

Prediction shifts are analyzed using:

- Change rate
- Wilcoxon Signed-Rank Test
- Rank-biserial correlation effect sizes

## Dataset

Experiments are conducted using learner essays from the ASK corpus.

The dataset contains Norwegian second-language learner essays annotated with CEFR proficiency levels ranging from A2 to C1, including intermediate labels:

- A2
- A2/B1
- B1
- B1/B2
- B2
- B2/C1
- C1

## Main Findings

### Predictive Performance

- CEFR descriptor prompting consistently outperformed baseline and one-shot prompting.
- Llama 3 achieved the strongest overall predictive performance.
- EuroLLM and NorMistral exhibited a tendency to over-predict the B1 proficiency level.
- Llama 3 showed a stronger preference for B2 predictions.

### Fairness

- All evaluated models exhibited sensitivity to at least some demographic variables.
- NorMistral demonstrated the highest degree of prediction instability.
- Several demographic values produced statistically significant prediction shifts despite identical essay content.
- Occupation, first language, and regional information were among the most influential demographic factors.

These findings highlight potential fairness concerns when deploying LLM-based assessment systems in educational settings.
